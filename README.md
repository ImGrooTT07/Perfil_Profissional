# Perfil Profissional com HTML e CSS

Este projeto foi desenvolvido como atividade prática da disciplina de **Programação Web**.  
O objetivo da atividade foi aprender os conceitos básicos de **CSS** e aplicá-los para estilizar uma página HTML simples.

## 📌 Sobre o Projeto

A página representa um **perfil profissional simples**, contendo informações básicas como:

- Nome
- Área de estudo
- Sobre mim
- Habilidades
- Formas de contato

O projeto utiliza **CSS interno**, onde as regras de estilo são escritas dentro da tag `<style>` no próprio arquivo HTML.

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3

## 🎨 Recursos de CSS Utilizados

Durante o desenvolvimento foram aplicadas algumas propriedades básicas de CSS, como:

- `background-color` → cor de fundo da página  
- `font-family` → definição da fonte  
- `font-size` → tamanho do texto  
- `text-align` → alinhamento do texto  
- `text-transform` → transformação do texto em maiúsculo  
- `font-style` → estilo da fonte (itálico)  
- `font-weight` → negrito  
- `width` e `height` → controle do tamanho da imagem  
- `text-decoration` → remoção do sublinhado dos links  

## 📷 Estrutura da Página

A página foi organizada utilizando algumas **tags semânticas do HTML**, como:

- `<header>` → área do topo com foto e nome
- `<main>` → conteúdo principal
- `<section>` → seções "Sobre mim" e "Habilidades"
- `<footer>` → área de contatos
